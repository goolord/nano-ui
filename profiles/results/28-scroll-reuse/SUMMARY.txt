Phase 5B (partial): reuse layout for scroll containers
date: 2026-09-12 (Linux x86_64, GHC 9.14.1, -O2 -mavx2, RTS -N1 -A64m -T -I0)
NOTE: SDL_VIDEODRIVER=dummy SDL_RENDER_DRIVER=software (X display dead).

Scroll containers were excluded from whole-layout reuse because the solver
writes their value/content-width columns (style 12/13) after the build, so a
naive descriptor compare never matched. Now styleMatch skips columns 12/13
for scroll nodes, and restoreLayoutCache copies the whole style column back
alongside geom, so the solver-computed content size is restored while
non-scroll widget values are still compared and preserved.

Floating nodes (windows/modals/popups) remain excluded. Pure scrolling only
changes the transform in applyScrollOffsets, so it stays on the cached path.
