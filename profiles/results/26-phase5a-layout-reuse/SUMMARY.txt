Phase 5A: whole-layout reuse
date: 2026-09-12 (Linux x86_64, GHC 9.14.1, -O2 -mavx2, RTS -N1 -A64m -T -I0)
NOTE: X display dead; bench + demo use SDL_VIDEODRIVER=dummy
SDL_RENDER_DRIVER=software. Verified equal to real driver for ui/runFrame.

What: on every frame the node arena is rebuilt and then fully re-solved.
When the rebuilt tree's layout-relevant descriptor is byte-identical to the
previous solved frame, restore the solved rects and skip the solve.

Implementation:
- NanoUI.Layout.Arena: LayoutCache (preallocated geom/style/tags/tree/text/
  options arrays) + newLayoutCache/captureLayoutCache/layoutInputsMatch/
  restoreLayoutCache. Capture is a memcpy into the existing cache arrays, so a
  steady frame allocates nothing.
- layoutInputsMatch compares, exactly and without hashing: node count, style
  columns, tag columns, tree columns, and Text/[Text] store equality; and it
  refuses reuse when any node is floating or a scroll container (their solve
  writes columns outside geom). 
- Context: ctxLayoutCache + ctxMetricGen; clearMeasureCache and setTheme bump
  the generation and drop the cache (font/DPI/theme change invalidation).
  hasCustomLayoutInputs disables reuse when a custom measure exists.
- Frame: tryReuseLayout before the first solve, captureLayout after a full
  solve (both first and layoutDirty passes).

fall back to the exact full solve.
