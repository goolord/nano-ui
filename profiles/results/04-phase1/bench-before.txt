nano-ui-sdl-profile: The following run time system options may be available (note that some

nano-ui-sdl-profile: 
nano-ui-sdl-profile:   -?        Prints this message and exits; the program is not executed
nano-ui-sdl-profile:   --info    Print information about the RTS used by this program
nano-ui-sdl-profile: 
nano-ui-sdl-profile:   --nonmoving-gc
nano-ui-sdl-profile:             Selects the non-moving mark-and-sweep garbage collector to
nano-ui-sdl-profile:             manage the oldest generation.
nano-ui-sdl-profile:   --copying-gc
nano-ui-sdl-profile:             Selects the copying garbage collector to manage all generations.
nano-ui-sdl-profile: 
nano-ui-sdl-profile:   -K<size>  Sets the maximum stack size (default: 80% of the heap)
nano-ui-sdl-profile:             e.g.: -K32k -K512k -K8M
nano-ui-sdl-profile:   -ki<size> Sets the initial thread stack size (default 1k)  e.g.: -ki4k -ki2m
nano-ui-sdl-profile:   -kc<size> Sets the stack chunk size (default 32k)
nano-ui-sdl-profile:   -kb<size> Sets the stack chunk buffer size (default 1k)
nano-ui-sdl-profile: 
nano-ui-sdl-profile:   -A<size>  Sets the minimum allocation area size (default 4m) e.g.: -A20m -A10k
nano-ui-sdl-profile:   -AL<size> Sets the amount of large-object memory that can be allocated
nano-ui-sdl-profile:             before a GC is triggered (default: the value of -A)
nano-ui-sdl-profile:   -F<n>     Sets the collecting threshold for old generations as a factor of
nano-ui-sdl-profile:             the live data in that generation the last time it was collected
nano-ui-sdl-profile:             (default: 2.0)
nano-ui-sdl-profile:   -Fd<n>    Sets the inverse rate which memory is returned to the OS after being
nano-ui-sdl-profile:             optimistically retained after being allocated. Subsequent major
nano-ui-sdl-profile:             collections not caused by heap overflow will return an amount of
nano-ui-sdl-profile:             memory controlled by this factor (higher is slower). Setting the factor
nano-ui-sdl-profile:             to 0 means memory is not returned.
nano-ui-sdl-profile:             (default 4.0)
nano-ui-sdl-profile:   -n<size>  Allocation area chunk size (0 = disabled, default: 0)
nano-ui-sdl-profile:   -O<size>  Sets the minimum size of the old generation (default 1M)
nano-ui-sdl-profile:   -M<size>  Sets the maximum heap size (default unlimited)  e.g.: -M256k -M1G
nano-ui-sdl-profile:   -H<size>  Sets the minimum heap size (default 0M)   e.g.: -H24m  -H1G
nano-ui-sdl-profile:   -xb<addr> Sets the address from which a suitable start for the heap memory
nano-ui-sdl-profile:             will be searched from. This is useful if the default address
nano-ui-sdl-profile:             clashes with some third-party library.
nano-ui-sdl-profile:   -xn       Use the non-moving collector for the old generation.
nano-ui-sdl-profile:   -m<n>     Minimum % of heap which must be available (default 3%)
nano-ui-sdl-profile:   -G<n>     Number of generations (default: 2)
nano-ui-sdl-profile:   -c<n>     Use in-place compaction instead of copying in the oldest generation
nano-ui-sdl-profile:             when live data is at least <n>% of the maximum heap size set with
nano-ui-sdl-profile:             -M (default: 30%)
nano-ui-sdl-profile:   -c        Use in-place compaction for all oldest generation collections
nano-ui-sdl-profile:             (the default is to use copying)
nano-ui-sdl-profile:   -w        Use mark-region for the oldest generation (experimental)
nano-ui-sdl-profile:   -I<sec>   Perform full GC after <sec> idle time (default: 0.3, 0 == off)

nano-ui-sdl-profile: 
nano-ui-sdl-profile:   -T         Collect GC statistics (useful for in-program statistics access)
nano-ui-sdl-profile:   -t[<file>] One-line GC statistics (if <file> omitted, uses stderr)
nano-ui-sdl-profile:   -s[<file>] Summary  GC statistics (if <file> omitted, uses stderr)
