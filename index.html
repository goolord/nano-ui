An immediate-mode GUI toolkit for Haskell

Describe your interface as a single action that runs every frame. button returns a Bool, mutable state lives in Vars, and the event loop sleeps until the next input arrives.

The code

A complete windowed counter alongside the Numbers panel running in the Controls tab above.

  • button draws a control and returns whether it was clicked on this frame. There are no callbacks to register and no widget objects to keep in sync.
  • useVar preserves a value between frames. Input widgets mutate their Var directly, and calling readVar below them reflects the new value on the same frame.
  • Build screens with ordinary Haskell control flow (when, case, for_). Components are plain functions, and layout modifiers compose with (.).

What's included

Widgets
Text editing with IME support, sortable tables, trees, tabs, menus, modals, floating windows, dockable pane grids, charts, and Markdown. Try all of them in the browser cookbook.
Layout
Rows, columns, grids, layers, wrapping, and scrolling, controlled by composable Layout -> Layout modifiers.
State
Mutable Vars updated directly by widgets, or an optional Elm-style message and update loop.
Text
TrueType fonts shaped with HarfBuzz, bidirectional text, fallback fonts, and rich inline styling.
Drawing
A 2D vector canvas with paths and gradients, images, SVG icons, eased tweens, and spring physics.
Themes
Light and dark themes, Base16 palettes, OS appearance tracking, and subtree-scoped styling.
Idle cost
The event loop sleeps until input, a timer, or a background task arrives, and frames repaint only the regions that changed.
Backends
SDL3 for desktop, RGFW with OpenGL and a bundled bitmap font, and the browser via GHC's WebAssembly backend and WebGL2.
Testing
Run views headlessly with scripted input and no window required, or export any frame directly to SVG.
Requires
GHC 9.10 through 9.14. MIT license.

Run it locally

Launch the full widget cookbook as a desktop app from a clone. nix develop provides GHC, Cabal, SDL3, and SDL3_ttf.

git clone https://github.com/goolord/nano-ui
cd nano-ui
nix develop
cabal run nano-ui-sdl-demo

To use nano-ui in your own project, add nano-ui and nano-ui-sdl to build-depends. See the quick start for Windows and non-Nix setups, then follow the tutorials to build a todo list, a notepad, and a live chart.
