An immediate-mode GUI toolkit for Haskell

Describe your interface as a single action that runs every frame. button returns a Bool, mutable state lives in Var values, and the event loop sleeps until the next input arrives.

The code

Counter app alongside live snippets running above.

Source 
import Data.Text qualified as T
import NanoUI
import NanoUI.Backend.Sdl (defaultSdlOptions, runSdlApp)

main :: IO ()
main = runSdlApp defaultSdlOptions counter

counter :: NanoUI ()
counter = row $ do
  n <- useVar (0 :: Int)
  whenM (button "-") (modifyVar n (subtract 1))
  label . T.pack . show =<< readVar n
  whenM (button "+") (modifyVar n (+ 1))
numbers :: NanoUI ()
numbers = do
  volume <- useVar 40
  count <- useVar (12 :: Double)
  field "Volume" $ rowWith (tight . gap 10 . alignMid . fillW) $ do
    sliderWith fillW 0 100 volume
    labelWith (tight . fixedW 36 . alignEnd) . percentage =<< readVar volume
  -- Reads the value written by the slider in the same frame.
  progressBar . (/ 100) =<< readVar volume
  field "Count (type or use arrow keys)" (numericInput count)
  where
    percentage v = T.pack (show (round v :: Int)) <> "%"
bloom <- do
  p <- animateTo bouncy . nearest =<< readVar petals
  l <- animateTo bouncy . nearest =<< readVar rings
  t <- animateTo bouncy =<< readVar twist
  d <- animateTo bouncy =<< readVar depth
  a <- readVar angle; i <- readVar swatch
  inner <- animateToA fade (colorAt i)
  mid <- animateToA fade (colorAt (i + 1))
  outer <- animateToA fade (colorAt (i + 2))
  pure (Bloom p l t d a inner mid outer)
resp <-
  if capSurfaceShaders caps
    then withCursorShape UiCursorGrab (shaderBox' (grow . minH 200) bloomShader bloom)
    else canvasConfigured flowerCfg (drawBloom bloom)
whenM (readVar spin) (keepAnimating resp)
drag <- useDrag2DOn resp
when (dragActive drag) (modifyVar angle (+ turned (respRect resp) drag))

  • Direct return values

    button draws a control and returns whether it was clicked on this frame. No callbacks or retained widget handles.

  • Same-frame state reads

    useVar preserves state between frames. Input widgets mutate their Var in place, so readVar below updates immediately.

  • Plain Haskell control flow

    Branch with when, case, and for_. Components are ordinary functions and layout modifiers compose with (.).

What's included

GHC 9.10-9.14 · MIT · Companion packages

Idle cost
Event loop sleeps until input, a timer, or a background task arrives; frames repaint only damaged regions.
Backends
SDL3 for desktop, RGFW + OpenGL with a bundled bitmap font (no system deps), and WebAssembly + WebGL2.
Widgets
IME text editing, sortable tables, trees, tabs, menus, modals, windows, dockable panes, charts, Markdown (sampler).
Layout
Rows, columns, grids, layers, wrapping, and virtualized scrolling via composable Layout -> Layout modifiers.
State
Mutable Var values updated directly by widgets, record field projections, or Elm reducers via nano-ui-emit.
Text
TrueType fonts shaped with HarfBuzz, bidirectional layout, system and fallback fonts, and rich inline styles.
Drawing
2D vector canvas with paths, strokes, gradients, images, SVG icons, eased tweens, and spring physics.
Themes
Light and dark themes, Base16 palettes, OS appearance tracking, and subtree-scoped styled overrides.
Testing
Headless scripted clicks, typing, and layout assertions with no window open, plus direct SVG frame export.

Run it locally

git clone https://github.com/goolord/nano-ui
cd nano-ui
nix develop
cabal run nano-ui-sdl-demo
build-depends:
  base >= 4.20,
  text,
  nano-ui ^>= 0.2,
  nano-ui-sdl ^>= 0.2

nix develop supplies GHC, Cabal, SDL3, and SDL3_ttf and launches the full desktop widget sampler.
