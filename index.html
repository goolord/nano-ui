An immediate-mode GUI toolkit for Haskell

You write the window as one action, and it runs again on every frame. button returns a Bool, state is held in Vars, and the loop sleeps until the next input.

Loading the demo

A nano-ui program with four tabs. Bloom draws a flower that sliders and a Shuffle button reshape. Controls, Text and Data hold buttons, choices, sliders, text fields, a table and a tree.

This is nano-ui running in the page: Landing.hs and Bloom.hs, compiled to WebAssembly. The same view opens in a desktop window on SDL3. With the keyboard, Tab to the demo and press Enter; Esc returns to the page.

The code

A whole program, and the function behind one panel of the demo.

  • button draws a button and returns whether it was clicked. There are no callbacks to register and no widget objects to update.
  • useVar keeps a value between frames. An input widget takes a Var and edits it; readVar anywhere else shows the new value on the same frame.
  • Control flow is Haskell's: when, case, for_. A component is a function, and layout is a modifier composed with (.).

What is in it

Widgets
Text editing with IME, tables, trees, tabs, menus, modals, floating windows, pane grids, charts, Markdown. The cookbook runs all of them in the browser.
Layout
Rows, columns, grids, layers, wrapping and scrolling, sized by Layout -> Layout modifiers.
State
Vars that widgets read and write, or an Elm-style message and update loop.
Text
TrueType fonts shaped by HarfBuzz, bidirectional text, fallback fonts, rich text.
Drawing
A canvas with vector paths and gradients, images, SVG icons, tweens and springs.
Themes
Light and dark, Base16 palettes, system appearance, styles scoped to a subtree.
Idle cost
The loop blocks until input, a timer or a background task wakes it. A frame repaints the region that changed.
Backends
SDL3. RGFW with OpenGL and a bundled bitmap font. The browser, through GHC's WebAssembly backend and WebGL2.
Tests
Frames run without a window, with scripted input. Frames export to SVG.
Requires
GHC 9.10 to 9.14. MIT licence.

Run it

The cookbook as a desktop program, from a checkout. nix develop provides GHC, Cabal, SDL3 and SDL3_ttf.

git clone https://github.com/goolord/nano-ui
cd nano-ui
nix develop
cabal run nano-ui-sdl-demo

In a project of your own, add nano-ui and nano-ui-sdl to build-depends. The quick start has the setup for Windows and for systems without Nix, and the tutorials build a todo list, a notepad and a live chart from there.
