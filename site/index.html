An immediate-mode GUI toolkit for Haskell

You write the window as one action, and it runs again on every frame. button returns a Bool, state is held in Vars, and the loop sleeps until the next input.

A complete program

import Data.Text qualified as T
import NanoUI
import NanoUI.Backend.Sdl (defaultSdlOptions, runSdlApp)

main :: IO ()
main = runSdlApp defaultSdlOptions counter

counter :: NanoUI ()
counter = row $ do
  n <- useVar (0 :: Int)
  whenM (button "-") (modifyVar n (subtract 1))
  label . T.pack . show =<< readVar n
  whenM (button "+") (modifyVar n (+ 1))

button draws a button and returns whether it was clicked. There are no callbacks to register and no widget objects to update.

useVar keeps a value between frames. An input widget takes a Var and edits it: slider 0 100 volume.

Control flow is Haskell's: when, case, for_. A component is a function.

What is in it

Widgets
Text editing with IME, tables, trees, tabs, menus, modals, floating windows, pane grids, charts, Markdown.
Layout
Rows, columns, grids, layers, wrapping and scrolling, sized by Layout -> Layout modifiers composed with (.).
State
Vars that widgets read and write, or an Elm-style message and update loop.
Text
TrueType fonts shaped by HarfBuzz, bidirectional text, fallback fonts, rich text.
Drawing
A canvas with vector paths and gradients, images, SVG icons, tweens and springs.
Themes
Light and dark, Base16 palettes, system appearance, styles scoped to a subtree.
Idle cost
The loop blocks until input, a timer or a background task wakes it. A frame repaints the region that changed.
Backends
SDL3. RGFW with OpenGL and a bundled bitmap font. The browser, through GHC's WebAssembly backend and WebGL2.
Tests
Frames run without a window, with scripted input. Frames export to SVG.
Requires
GHC 9.10 to 9.14. MIT licence.
